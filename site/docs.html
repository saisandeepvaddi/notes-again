Self-hosting

Notes Again is one server process that serves both the app and its API and keeps everything in a single SQLite file. There are no other services to run. Every setup signs in with a username and password by default and keeps a daily snapshot of the database. Every option builds from the source you clone; there is no prebuilt image.

On your computer

Needs git, Rust, Node 22+ and pnpm.

git clone https://github.com/saisandeepvaddi/notes-again && cd notes-again
make run

This builds the frontend and serves Notes Again on http://127.0.0.1:8000.

On a server, guided

Needs git, plus Docker or Rust, Node and pnpm; the script asks which.

curl -fsSL https://raw.githubusercontent.com/saisandeepvaddi/notes-again/main/install.sh | sh

Docker Compose, by hand

git clone https://github.com/saisandeepvaddi/notes-again && cd notes-again
docker compose up -d --build

On first launch, sign in as admin with the temporary password printed in the server output, then choose your own username and password, turn login off, or switch to Firebase sign-in.

Sign-in modes, reverse proxies and tunnels, API tokens and settings are covered in the full guide: docs/self-hosting.md.

Desktop app

A Tauri shell around the regular app. It runs its own copy of the server on 127.0.0.1 with a database in your OS app-data folder, so it works with no server at all, and every request needs a per-launch secret so other programs on the machine can't read your notes.

  • Closing the window keeps it in the tray (menu bar on macOS) so sync and reminders continue.
  • A notification says when notes become due.
  • Cmd/Ctrl+Alt+Shift+N opens a new note from anywhere.
  • Settings, then Sync, connects it to a server you run. It syncs in the background and keeps working offline; a note edited in two places gets a side-by-side compare.

Details: desktop/README.md. Installers are on the download page.

Browser extension

Notes Again Capture (Chrome, Edge, Brave and Firefox) saves the current page or a text selection as a note.

  • Save page: toolbar button, Alt+Shift+N, or right-click. Choose Link only or Readable article (the main article as editable Markdown).
  • Save selection: right-click a selection, or Alt+Shift+S.
  • A dialog lets you edit the name, Markdown, project and tags before saving. Readable articles default to Note only, without a review schedule.
  • Article extraction runs in your browser, with no remote service.

To set it up, create a token under Settings, then API tokens in the web app and paste it into the extension's options with your server URL. With the desktop app, use Settings, then Phone & extension to create a connection link. The token can only create notes, projects and tags; it can't read, edit or delete anything. Build instructions and details: extension/README.md.

Importing

Bulk import accepts an Anki-like JSON structure (decks, per-day limits, notes with tags and difficulty) with a dry-run summary step before anything is committed.

Backups

Settings, then Data & backups, shows where the database file is and every local snapshot. You can download the database, take a snapshot now, or download any snapshot.

  • Snapshots run every 24 hours by default and keep the last 7. They sit on the same disk as the database, so they don't protect against losing the disk.
  • Off-site backup to S3-compatible storage is available through Litestream.
  • The desktop app can also choose the snapshot folder (for example one synced by iCloud Drive or Dropbox) and restore a snapshot.
  • The binary has a restore command for replacing the database with a snapshot or downloaded file.

Full instructions: backups in docs/self-hosting.md.
