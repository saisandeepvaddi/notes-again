A notebook that makes you remember what you wrote.

Write anything worth keeping as freeform Markdown, file it under projects and tags, and Notes Again brings each note back for review on an FSRS or SM2 schedule, so it sticks instead of being written once and forgotten.

Download the desktop app View source on GitHub

This project is vibe-coded for personal use. It is built with AI assistance for one person's daily workflow, with no support promises. Read the code, back up your data and expect rough edges before you rely on it.

How it differs from other notebooks

  • Spaced repetition on real notes

    Not flashcards: a note can be a full explanation with code blocks, and you rate recall (Again / Hard / Good / Easy) when it comes back. Notes you only want to keep can opt out of review.

  • Yours, on your machine

    One SQLite file, no account, no cloud. The desktop app works offline, and your devices sync through a server you run (or directly with your phone over Wi-Fi).

  • Plain Markdown in and out

    Copy or download any note (with its images and PDFs) as Markdown, import Anki-style decks and keep automatic backups.

  • AI only on your terms

    Optional "Discuss this note" uses your own OpenAI or Anthropic key, sends only the note you are viewing and saves nothing unless you confirm.

  • Capture and connect

    A browser extension clips pages or readable articles, notes link to each other with backlinks, and every note keeps a history you can compare and restore.

Status

Working today: notes, projects, tags, review sessions, trash, attachments, note history, note links and backlinks, single-note AI discussion, sync, and the web, desktop, iOS and extension clients.

Planned: chat across selected notes or the whole library, favorites and saved searches, reading mode and templates (plan). Android is untested.

Mobile apps are not distributed yet. The desktop installers are not code-signed.

Get started

Install the desktop app, which needs no server, or run your own server for the web app and syncing between devices.
