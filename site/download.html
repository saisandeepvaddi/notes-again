Download

The desktop app runs everything on your computer, needs no server, and checks for updates itself. Connect it to a server later (Settings, then Sync) to use the same notes on other devices.

Every button opens the latest release on GitHub, where all installers are listed.

The builds are not code-signed. macOS and Windows ask you to confirm the first launch. This is a personal, open-source project, so the installers are unsigned.

First launch

macOS

The app isn't notarized, so the first time, right-click it in Applications and choose Open. On macOS 15 and later: System Settings, then Privacy & Security, then Open Anyway.

Windows

SmartScreen may warn about an unrecognized app: choose More info, then Run anyway.

Linux

Use the .AppImage (it updates itself), or the .deb / .rpm for your package manager.

Browser extension

Notes Again Capture saves the current page, a readable article or a text selection as a note, in Chrome, Edge, Brave and Firefox. Build and load it from the extension folder; see the extension docs.

Mobile

The mobile app is not distributed yet. The code is in the repository if you want to build it yourself.

Prefer a server?

To use the web app or sync several devices, run your own server. Everything builds from source you clone.
